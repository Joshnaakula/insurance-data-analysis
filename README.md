# insurance-data-analysis
Insurance cost analysis using Python and Tableau
## Health Insurance Data Analysis & Tableau Dashboard

**Project Overview**
This project analyzes health insurance customer data to understand how medical conditions and hospital factors impact insurance charges.
The analysis combines Python (data cleaning & merging) and Tableau (data visualization & storytelling) to deliver clear business insights.

**Objectives**
1. Analyze insurance charges based on age, BMI, medical history, and hospital tier

2. Identify high-risk groups driving higher insurance costs

3. Build an interactive Tableau dashboard with KPI cards and charts

4. Present insights using data storytelling

**Dataset Description**
The project uses multiple datasets that are merged into a single analysis-ready file.

Age group

**Key Insights**
Customers with heart issues incur higher insurance charges

Cancer history significantly impacts average cost

Tier-1 hospitals have the highest insurance charges

Higher BMI and age correlate with increased costs
